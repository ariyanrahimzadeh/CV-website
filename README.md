## Portfolio Website

- **Dark glassmorphic Bento Grid UI** presents profile information and projects in a polished, scannable layout.
- **Vanilla JavaScript category filtering** lets visitors browse AI/ML, Unreal Engine, and web projects.
- **Responsive mobile navigation** adapts the site to smaller screens.
- **Zero-dependency static deployment** keeps the site lightweight and easy to host with GitHub Pages.

## Local Quick Start

1. Clone the repository: `git clone https://github.com/ariyanrahimzadeh/web.git`
2. Open `index.html` in a browser, or open the folder in VS Code and launch it with the Live Server extension.

> To enable the CV download button, add the PDF at `assets/ENG_CV.pdf`.
